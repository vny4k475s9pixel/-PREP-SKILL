# short-video-prep-script

短视频口播脚本创作方法论 skill，基于 **PREP 结构**（观点-理由-举例-总结）与**爆款选题规律**，覆盖四类结构类型。

## 它能做什么

把短视频口播脚本的创作从"靠感觉"变成"可复制的流程"。核心主张：**网感 = 艺术 40% + 科学 60%**——掌握选题逻辑与 PREP 结构，即可稳定达到 60% 的网感水准。

适用于：撰写口播脚本、拆解爆款视频结构、选题策划、评估选题爆款潜力。

## 目录结构

```
short-video-prep-script/
├── SKILL.md                             # 主入口：核心框架 + 工作流 + 结构类型决策
└── references/
    ├── prep-structure.md                # PREP 四段逐段拆解（目标/时长/话术技巧）
    ├── four-structure-types.md          # 四类结构类型完整模板
    └── hot-selling-patterns.md          # 十二条爆款规律框架 + 网感公式
```

## 核心框架

```
P — Point   观点/问题   3-5 秒
R — Reason  理由/原因   10-15 秒
E — Example 举例/方法   15 秒后（主体）
P — Point   观点/总结   10-15 秒
```

## 四类结构类型

| 类型 | 适用场景 | E 段展开方式 |
|------|----------|-------------|
| 大故事 | 有长故事、靠情绪爽点 | 大故事七步曲 |
| 方法干货 | 实用类、教程类 | 方法三步曲 × N |
| 小故事 | 小故事引出方法论 | 小故事 + 方法论 |
| 观点 | 认知输出、态度类 | 正反案例论证 |
